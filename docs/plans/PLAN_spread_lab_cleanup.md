### 설계 결정

1. **판정을 지우고 수치와 잰 기간을 보인다** (결정 5 (가) · 1-5)
   - 판정 함수 셋(`_render_overfitting_interpretation` · `_render_fixed_b_interpretation` · `_render_rmse_interpretation`) · 판정 상자 · 임계값 상수 둘, 「인샘플 / 아웃오브샘플」 라벨, 그 판정을 정해 둔 「해석 방법」 줄을 지운다. 금리 구간별 해석 한 줄도 같은 판정 함수 안이라 함께 — 수치(저금리 · 고금리 RMSE · 거래일 수)는 남는다
   - 대신 데이터에서 읽은 기간을 보인다: 튜닝 결과의 최적 RMSE 아래에 「튜닝 전체기간(정적 spread 시계열의 첫 월 ~ 끝 월)에서 잰 값 — 워크포워드 RMSE 와 잰 기간이 달라 직접 비교하지 않는다」, 이어 붙인 RMSE 셋 위에 「같은 테스트 구간(테스트 월의 처음 ~ 끝)」. 「해석 방법」은 「완전 고정 · b 고정의 a · b 는 테스트 구간까지 본 전체기간 튜닝값이라 셋의 차이를 아웃오브샘플 성능 차이로 읽지 않는다」로
   - 세 워크포워드 결과의 테스트 월이 하나라도 다르면 「같은 테스트 구간」 문구가 거짓이 되므로 ValueError 로 멈춘다(`_common_test_period`)
   - 섹션 이름: 「과최적화 진단 (완전 고정 a,b)」 → 「워크포워드 RMSE 비교 (완전 고정 · b 고정 · 동적)」, 「b 고정 워크포워드 검증 (과최적화 진단)」 → 「… (b = 전체기간 최적값)」. 읽기 가이드 표 · 상세 분석 안내 상자 · 모듈 docstring 도 같은 이름으로. docstring 에 「판정하지 않는 이유」 한 단락
   - `tqqq/constants.py` 의 「(과최적화 검증 완료)」 → 「전체기간 튜닝 최적값 (스프레드 랩 튜닝 결과의 RMSE 최소 행)」, `src/qbt/tqqq/CLAUDE.md` 의 같은 괄호 → 아래 근거 승격 문장
2. **같은 수치는 한 곳에** (7-2)
   - 로더는 셋: `_read_csv(path, mtime)`(캐시) · `_load_csv(path)` · `_load_summary(path) -> dict[str, float]`(`strict=True`)
   - 같은 차트 두 벌 중 2선 차트를 지운다(3선 차트에 두 선이 다 있다)
   - 다른 곳에 있는 수치만 다시 보이던 줄을 지운다 — 상세 분석의 「RMSE 정합 비교」 줄(정적 · 동적 이어 붙인 · 월별 리셋 평균), b고정 섹션의 RMSE 3칸 줄, 비교 섹션의 정적 RMSE 칸(튜닝 섹션의 「최적 RMSE」와 같은 값). 「RMSE 정합 비교」가 하던 설명 중 남길 것(월별 리셋 평균은 누적 오차가 상쇄돼 작게 나온다)은 워크포워드 상세 요약의 용어 설명으로 옮긴다
   - 그래서 b고정 섹션에는 파라미터 안정성 비교만 남는다
3. **죽은 분기 · 기본값 넘김을 지운다** (6-10 · 12-9 · 6-7) — 결과 CSV 는 직접 읽고(없으면 FileNotFoundError), 요약 값은 직접 인덱싱한다. 차트 단위 try/except 를 지운다(델타 섹션의 ValueError 분기 포함 — 탈 길이 없다)
