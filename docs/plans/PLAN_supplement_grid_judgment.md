### 설계 (코드)

**새 모듈 `src/qbt/backtest/supplement_experiment.py`** — 도메인 로직(구성 만들기 · 지표 · 판정)을 두고 테스트로 고정한다(D21 「규칙은 src, 러너는 scripts」). 공개 함수:

- `build_experiment_config(q2_2xs_slots, candidate, w_pct, variant, start_date) -> PortfolioConfig` — 위 표대로 매매법 두 개를 만든다. Q-2-2XS 슬롯을 인자로 받는 이유: `portfolio_configs` 가 등록 실험을 이 함수로 만들므로 이 모듈이 `portfolio_configs` 를 import 하면 순환 import 다(SoT 는 `portfolio_configs` 의 `portfolio_q2_2xs`). 몫은 `(100 − w_pct) / 100` · `w_pct / 100`. Q-2-2XS 단독은 `candidate="q2_2xs"`(매매법 하나, `portfolio_q2_2xs` 슬롯 그대로). `min_start_date` 는 `start_date` 로 채운다. 실험 이름은 `portfolio_q2_2xs_{후보}{w}`(판이 `spliced` 가 아니면 `_{판}` 접미사)
- `summarize_run(result) -> dict` — 반올림 전 CAGR · MDD · Calmar(엔진 `result.summary`, 반올림 전 값임을 확인함), 시작 · 끝날, 매도 거래 수, 회전율(상태 로그의 `{키}_exec_shares × {키}_exec_price` 를 매수 · 매도 모두 더해 평균 자본과 연수로 나눈 연 회전율), 국면별 수익률 · 구간 MDD(위 세부 표의 계산)
- `extract_decision_targets(state_log_df, method_id)` · `decision_agreement(targets_a, targets_b)` — 위 「신호 일치율」 정의. 병렬 워커가 결과 전체(상태 로그 수 MB)를 넘기지 않도록 월말 판단 비중표만 뽑아 넘긴다
- `build_grid_cases()` · `run_grid_case(case, q2_2xs_slots)` — 실행 목록(149)과 병렬 워커(실행 → 정합성 검사 → 요약 → 판단 비중표). 워커는 결과의 첫 날짜가 묶음 시작일과 다르면 ValueError — 엔진의 `start_date` 는 하한이라 데이터가 늦게 시작하는 구성은 조용히 늦게 시작해 같은 기간 비교가 깨진다
- `compute_advantages(results)` — 같은 시작일 · 같은 w 의 기준선 대비 Calmar 우위
- `gate_agreement(proxy_adv, real_adv)` — 판정 일치(w 별 부호 일치 · 고원 일치). Calmar 차이는 러너가 행에 싣는다
- `find_plateaus(flags)` · `judge(main_adv, sub_adv, sub_only)` — 후보별 D24 판정(D47), 고원 구간(여럿이면 모두). 「높다」는 반올림 전 값의 엄격한 `>`
- `collect_judgments(results)` · `collect_gates(results)` — 어느 실행을 어느 실행과 비교하는지(판정 기준 두 가지 · 관문 다섯)를 모아 행으로 낸다. 러너는 반올림 · 한글 헤더 · 저장만 한다
- 국면 구간 상수 — 위 세부 표

**새 러너 `scripts/backtest/run_supplement_grid.py`** (인자 없음) — 실행 목록 → 병렬 실행 → 실행마다 `validate_portfolio_result`(위반이면 그 구성과 함께 ERROR 로그 · 중단, 포트폴리오 러너와 같은 정책) → 반올림 전 값으로 관문 · 판정 계산 → `grid_runs.csv` · `judgment.csv` · `proxy_gate.csv` 저장(헤더는 `DISPLAY_*` 한글, 값은 위 자릿수) → 판정 · 관문 요약 출력 → 메타 저장

**설정 타입** (착수 전 결정 ① 이 (가) · (나)일 때) — `PortfolioConfig.min_start_date: date | None = None`. 포트폴리오 러너가 `max(엔진 시작일, 정책 하한, min_start_date)` 로 시작일을 정한다. 엔진은 이 칸을 읽지 않는다. 기존 설정은 기본값이라 결과가 바뀌지 않는다
