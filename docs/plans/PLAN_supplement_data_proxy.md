### 설계 (결정에서 구현으로)

**다운로드**

- 기존 `scripts/data/download_data.py TICKER` 로 14종을 하나씩 받는다. 결과는 `{TICKER}_max.csv`, 가격 6자리, 오늘 포함 최근 2일 제외라 2026-10-02 까지 들어온다. 저장 전에 기존 검증(결측 · 0 · 음수 · 하루 ±50%)을 통과해야 저장된다
- 분석 기준일 2026-09-24 는 다운로드가 아니라 분석 단계에서 자른다(D22). 실험은 엔진이 자산 시세의 교집합으로 기간을 정하고 SSO · QLD 가 2026-09-24 에서 끝나므로 자동으로 거기서 끝난다. 이 계획서의 측정은 명시적으로 2026-09-24 에서 자른다
- IWM · EFA · EEM 은 기존 파일을 덮어쓴다. 수정주가라 과거 행 값도 바뀔 수 있다(분배금 재조정) — `src` · `scripts` · `tests` 에서 세 티커 참조 0건이라 기존 결과에 영향이 없다

**대용 시계열 계산** (새 모듈 `src/qbt/utils/proxy_series.py` — 도메인과 무관한 시세 가공이라 utils)

- 세 함수 공통 입력 검증: 날짜가 엄격히 오름차순(중복 없음)이 아니면 `ValueError`. `load_stock_data` 가 정렬 · 중복 제거를 하지만 함수가 그 전제를 직접 확인한다(전역 「명시적 검증」)
- `rescale_to_actual(proxy_df, actual_df) -> DataFrame`: 이음매 = 실물 첫 거래일. 대용 **전 구간**의 가격 4열에 `실물 이음매 종가 ÷ 대용 이음매 종가` 를 곱한다(거래량은 그대로). 수익률은 바뀌지 않는다. 이음매 날짜가 대용에 없으면 `ValueError`
- `splice_proxy(proxy_df, actual_df) -> DataFrame`: `rescale_to_actual` 한 대용의 이음매 **이전** 행 + 실물 전 행. 이음매 이전 행의 거래량은 0 이다. 이음매 이전 대용 행이 없으면 `ValueError`. 결과 열은 `REQUIRED_COLUMNS`, 날짜 오름차순
  - 이음매 날의 종가 수익률은 대용의 수익률(스케일이 이음매 종가에 맞춰져 있으므로)이고, 그 다음 날부터는 실물 그대로다. 선례 `scripts/tqqq/generate_synthetic.py` 와 같은 종가 비율 접합이다
  - 거래량 0 도 선례와 같다 — `TQQQ_synthetic_max.csv` 의 상장 전 구간이 0 이다(2010-02-10 까지 0, 2010-02-11 부터 실물). 대용의 거래량은 실물의 거래량이 아니다
- `build_daily_rebalanced_composite(components: Sequence[tuple[DataFrame, float]]) -> DataFrame`: 매일 비율을 맞추는 바스켓
  - 입력 검증: 구성 2개 이상, 비중 > 0, 비중 합 1(허용 오차 `EPSILON`). 기간은 가장 늦은 시작일부터 가장 이른 끝날까지이고, 그 안에서 **구성 종목의 날짜 집합이 모두 같아야 한다**(다르면 다른 날짜를 담아 `ValueError` — 보간 금지 원칙)
  - 종가: 첫날 1.0, 이후 `C_t = C_{t−1} × Σ w_i × close_i,t ÷ close_i,t−1`
  - 시가 · 고가 · 저가: 같은 식에 그날 구성 종목의 시가 · 고가 · 저가를 넣는다(`X_t = C_{t−1} × Σ w_i × X_i,t ÷ close_i,t−1`, 첫날은 `C_{t−1}` 자리에 1.0 과 그날 종가 `close_i,0`). 구성 종목에서 고가 ≥ 시가 · 종가 ≥ 저가이면 합성에서도 성립한다. 거래량은 0
  - 고가 · 저가는 근사다(바스켓의 장중 고가는 구성 종목 고가의 가중합보다 낮을 수 있다). 엔진의 판단 · 체결 · 평가는 시가 · 종가만 쓰고, 고가 · 저가는 시그널 CSV 의 전일대비% 와 차트에만 쓰인다(`src/qbt/backtest` · `scripts/backtest` 검색 확인)
- VXUS 순수 합성판 = `rescale_to_actual(합성, VXUS)`. 그래서 순수판의 이음매 이전 행이 이어 붙인 판의 이음매 이전 행과 **같다**(같은 스케일 · 같은 거래량 0). 1:1 대용 3쌍의 순수판은 원본 파일(EFA · SHY · DBC)을 그대로 쓰고 새로 만들지 않는다(D39)

**생성 스크립트** (새 `scripts/data/generate_proxy_series.py`, 인자 없음)

- 입력을 `load_stock_data` 로 읽고 → 위 함수 → 가격 6자리 반올림 → 기존 `validate_stock_data`(다운로더가 저장 전에 쓰는 검증. 호출처 1 · 테스트 7곳, 순수 검증 함수) → 저장 → `save_metadata("proxy_series", …)`(파일마다 경로 · 행 수 · 기간 · 이음매 날짜 · 스케일). 순서는 다운로더(반올림 → 검증 → 저장)를 따른다
- 대용 구성표(대상 ← 대용, VXUS 합성 비중 0.75 · 0.25)는 이 스크립트만 쓰므로 스크립트 로컬 상수다
- 출력 파일: `VEA_synthetic_max.csv` · `BIL_synthetic_max.csv` · `PDBC_synthetic_max.csv` · `VXUS_synthetic_max.csv`(이어 붙인 판, 선례 `{TICKER}_synthetic_max.csv` 이름 규칙) · `VXUS_proxy_max.csv`(순수 합성판 — 실물 구간이 없어 `synthetic` 과 구별한다)
- 경로 상수는 이 계획서가 읽고 쓰는 파일만 `common_constants.py` 에 더한다 — 입력 EFA · EEM · VEA · VXUS · SHY · BIL · DBC · PDBC, 출력 5개. 기존 데이터 경로가 모두 그 파일에 있고(관용), 출력 경로는 ③-3 의 실험 설정(backtest)도 쓴다(D39)

**측정** (상관 · 수익 차 · VXUS 분해)

- 세션 스크래치의 스크립트로 재고, 결과는 설계서 8.3 에 측정 방법(기간 · 수익률 정의 · 회귀식)과 함께 도구 출력 그대로 적는다. **저장소에 남기지 않는 이유**: D23 이 상관 · 수익 차를 「보고만」으로 정했고, 통과 · 탈락을 가르는 관문 측정(판정 일치 · 신호 일치율)은 ③-3 의 그리드 러너가 맡는다. 방법을 문서에 적어 재현할 수 있게 한다
- 쌍마다 겹치는 기간 = 실물 첫 거래일부터 2026-09-24 까지. 대용 쪽은 1:1 쌍이 원본 파일, VXUS 가 순수 합성판(가격 수준은 수익률에 영향 없음)
  - 일간 종가 수익률 상관, 월간(월 마지막 거래일 종가) 수익률 상관
  - CAGR · MDD 를 대용 · 실물 각각 재고 차이를 적는다(산식은 저장소 `calculate_summary` 와 같은 정의 — CAGR 은 `ANNUAL_DAYS` 연환산, MDD 는 종가 고점 대비)
- VXUS 분해: VXUS 주간 수익률(주 마지막 거래일 종가)을 VEA · VWO 주간 수익률에 절편 포함 최소제곱으로 회귀해 계수와 설명력(R²)을 적는다. 기간은 VXUS 첫 거래일부터 2026-09-24 까지. S1 예비값은 「VEA 약 75% + VWO 약 25%, 설명력 99.3 – 99.9%」였다(설계서 5.1)
- 분해 계수가 0.75 · 0.25 와 뚜렷이 다르면(판단 기준을 미리 숫자로 두지 않는다 — D23 과 같은 이유) 합성 비중을 바꿀지 사용자에게 묻는다. 바꾸면 스크립트 상수만 고쳐 다시 만든다
