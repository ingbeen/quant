## 2. 문제 정의

전체 기간 요약 지표(`summary.json`)는 숫자 하나다. 그래서 **최근 몇 해의 강한 성과가 그 숫자를 끌어올렸을 가능성**을 배제하지 못한다.
최근 성적이 좋았던 전략은 전체 기간 CAGR·Calmar도 높게 나오지만, 과거 시점에서 멈춰 보면 평범했을 수 있다.

이 연구가 답하는 질문은 둘이다.

1. **과거 시점에서 멈췄다면** 이 전략의 누적 성과는 어땠는가? 지금의 수치는 언제부터 관측되었는가?
2. **QQQ Buy & Hold 대비** 우열은 시기에 따라 어떻게 변했는가?

## 3. 측정 방법

### 누적 구간

시작일을 2007-04-09로 **고정**하고, 종료일만 각 연도의 마지막 거래일로 한 해씩 늘려가며 20개 구간을 만든다.

```
2007-04-09 ~ 2007-12-31
2007-04-09 ~ 2008-12-31
...
2007-04-09 ~ 2026-09-24
```

시작일이 2007-04-09인 이유는 SSO·QLD 상장(2006-06-21) 후 **SMA200 워밍업 199행**이 지나야 첫 신호가 나오기 때문이다.

### 지표 계산

- 각 구간은 `equity.csv`를 종료일까지 잘라 `calculate_summary()`에 그대로 넣는다. `summary.json`과 **같은 산식**이다.
- 엔진은 미래 데이터를 쓰지 않는다(체결 타이밍 규칙, hold_days lookahead 금지 — [src/qbt/backtest/CLAUDE.md](../../src/qbt/backtest/CLAUDE.md)).
  따라서 T일까지 자른 에쿼티는 **종료일을 T로 두고 백테스트를 돌린 결과와 같다.** 백테스트를 새로 돌리지 않았다.
- 마지막 구간의 값이 `summary.json`(CAGR 15.40 / MDD -27.56 / Calmar 0.56)과 일치함을 확인했다.

### QQQ Buy & Hold

- 같은 엔진(`run_backtest` + `BuyAndHoldStrategy`), 같은 가격 파일(`storage/stock/QQQ_max.csv`), 같은 기간, 같은 조건으로 실행했다.
  - 2007-04-09에 10,000,000원으로 시작해, 다음 날(2007-04-10) 시가에 매수하고 편도 비용 0.3%를 반영한다.
- 두 에쿼티 곡선의 거래일 4,898일이 완전히 일치함을 확인했다.
- 기존 `storage/results/backtest/buy_and_hold_qqq/` 결과는 1999년 시작이라 이 비교에 쓰지 않았다.

## 4. 용어 정의

| 용어 | 정의 |
| --- | --- |
| **누적 구간** | 시작일을 고정하고 종료일만 늘려가는 구간. 각 행은 "그 해 말에 이 백테스트를 돌렸다면 보였을 성적"이다 |
| **CAGR** | 그 구간 동안 매년 같은 비율로 불었다고 볼 때의 연평균 복리 수익률. `(최종 / 초기) ^ (365.25 / 일수) - 1` |
| **MDD** | 구간 안에서 직전 고점 대비 가장 크게 떨어진 폭 |
| **Calmar** | CAGR ÷ \|MDD\|. 최악의 하락 1%를 견딘 대가로 연수익을 몇 % 얻었는지 |
| **CAGR 차이** | Q-2-2XS 누적 CAGR − QQQ 누적 CAGR (%p). **양수면 Q-2-2XS가 앞선다** |
| **그 해 수익률** | 그 해 말 자산 ÷ 전년 말 자산 − 1. 2007년은 초기 자본 대비 |

## 6. 분석

### 6.1 최근 성적 덕분인가

누적 수치를 연말 시점별로 묶으면 네 국면이 보인다.

| 연말 시점 | 누적 CAGR | Calmar | 해석 |
| --- | --- | --- | --- |
| 2008 | -0.47% | -0.03 | 출발 직후 금융위기. 그 해 -5.27%로 방어했지만 벌지는 못했다 |
| 2009 ~ 2012 | 8.25 ~ 10.69% | 0.39 ~ 0.51 | 현재보다 확실히 낮다 |
| 2013 ~ 2019 | 11.87 ~ 15.50% | 0.56 ~ 0.74 | **현재와 같은 수준.** Calmar 최고점 0.74(2014) |
| 2020 ~ 2026 | 13.67 ~ 16.40% | 0.50 ~ 0.60 | 코로나 MDD 경신 이후 |

- **현재 수치는 2013~2019년 범위 안에 있다.** 지금의 CAGR 15.40%는 2014년 말(15.50%)과 거의 같고, Calmar 0.56은 2016년 말과 같다.
- **최근 구간은 Calmar를 끌어올리지 않았다. 오히려 낮췄다.** 2020년 코로나 급락이 누적 MDD를 -21.24%에서 -27.56%로 키웠고, 그 뒤 Calmar는 2019년 이전 최고치(0.74)를 회복하지 못했다.
- 최근 강한 해(2023년 +36.48%, 2024년 +33.80%)는 누적 CAGR을 2022년 말 13.67%에서 15.90%로 올렸다. 하지만 **이미 2014년(15.50%)과 2021년(16.40%)에 도달했던 수준으로 되돌아간 것**이지, 새 수준을 만든 것이 아니다.

### 6.2 QQQ 대비 CAGR: 세 국면

| 국면 | CAGR 차이 | 설명 |
| --- | --- | --- |
| 2008 ~ 2014 | +2.35 ~ +20.11%p | 2008년 한 해(Q-2-2XS -5.27% vs QQQ -41.73%)의 격차가 만든 우위 |
| 2015 ~ 2018 | +0.26 ~ +0.99%p | 우위가 줄어든다 |
| 2019 ~ 2026 | -1.27 ~ +0.67%p | 8개 연말 중 2번(2022·2024)만 앞섰다. 현재 -1.06%p |

- 2019년 이후 QQQ가 크게 오른 해(2019 +38.96%, 2020 +48.41%, 2023 +54.86%)에는 뒤처지고, QQQ가 크게 빠진 해(2022 -32.58%)에는 따라잡는 패턴이 반복된다.
- **해별 승부**: Q-2-2XS 8번(2008, 2012, 2013, 2014, 2017, 2021, 2022, 2024), QQQ 12번.
- **손실 연도**: Q-2-2XS 5번(2008, 2011, 2015, 2018, 2022), QQQ 3번(2008, 2018, 2022).
  - 손실 연도는 Q-2-2XS가 더 많다. 그러나 손실 폭은 작다. 최악의 해가 Q-2-2XS -19.99%(2022), QQQ -41.73%(2008)다.
  - 2011·2015년은 QQQ가 플러스인데 Q-2-2XS만 마이너스였다. 두 해 모두 주식을 비운 날이 있었다
    (상관계수 연구 9장: 2011년 40.1%, 2015년 18.3%). 추세추종이 횡보장에서 치르는 구조적 비용과 부합한다(전략_검증_보고서 §6.1).

요약하면 **수익은 QQQ와 비슷하거나 조금 낮고, 하락 폭은 절반**이다.

### 6.3 MDD 갱신 이력

**Q-2-2XS** — 누적 MDD가 네 번 경신되었다.

| 저점일 | 누적 MDD | 비고 |
| --- | --- | --- |
| 2007-11-21 | -12.71% | 첫 해 |
| 2008-11-03 | -18.67% | 금융위기 |
| 2009-07-07 | -21.04% | 금융위기 이후 |
| 2016-06-27 | -21.24% | 브렉시트 투표(2016-06-23) 직후 |
| 2020-03-12 | **-27.56%** | 코로나 급락. 이후 경신 없음 |

2022년 긴축기와 2025년 4월 급락도 -27.56%를 넘지 않았다.

**QQQ** — 2008-11-20에 기록한 -53.40%가 이후 한 번도 경신되지 않았다.

### 6.4 Calmar는 2008년 말 이후 매번 QQQ 우위

2008년 말부터 2026-09-24까지 **19개 연말 전부** Q-2-2XS의 Calmar가 QQQ보다 높다.
예외는 2007년 한 번뿐이다(0.51 vs 1.87). 금융위기 전 9개월이라 QQQ에 아직 큰 하락이 없던 구간이다.
현재 0.56 vs 0.31로 약 1.8배다.

### 워크포워드(WFO)와 다른 점

워크포워드는 과거 구간에서 파라미터를 고르고 그다음 구간에서 성적이 유지되는지를 반복해서 보는 검증이다.
이 저장소에서는 이번 질문에 답하지 못한다.

- **대상이 다르다.** QQQ·TQQQ 단일 자산(`buffer_zone_qqq`, `buffer_zone_tqqq`)만 실행했다. 포트폴리오 Q-2-2XS에는 WFO 결과가 없다.
- **목적이 다르다.** "파라미터를 다시 고르면 결과가 어떻게 되나"를 보는 도구다. "고정한 규칙의 성적이 시기마다 어땠나"를 보는 도구가 아니다.

> **[혼동 주의] 수익 집중도(Profit Concentration, PC).** 전체 수익 중 가장 많이 번 한 윈도우의 비율이다.
> QQQ 단일 자산 기준 0.4855(OOS 2023-03 ~ 2025-02 윈도우가 48.6%)라서 "최근 의존"의 증거처럼 보일 수 있다.
> 그러나 PC는 **금액 기준**(`end_equity - prev_end_equity`)이다. 복리가 쌓인 후반 윈도우가 구조적으로 커지므로
> 이 문서의 결론과 직접 비교할 수 없다.

### 수치 차이 주의

기존 문서의 Q-2-2XS 전체 성과(15.43% 등)는 **2026-08-21 데이터 기준**이다. 이 문서(15.40%)와의 차이는 데이터 기준일 차이이며 산식은 같다.
QQQ B&H도 마찬가지로 16.33%(2026-08-21) → 16.47%(2026-09-24)다.

## 9. 재현 방법

### 선행 조건

`storage/results/portfolio/portfolio_q2_2xs/equity.csv`가 존재해야 한다.
생성 방법은 [docs/COMMANDS.md](../COMMANDS.md)의 포트폴리오 백테스트 실행 명령 참조.

### 계산 코드

본 연구는 일회성 분석이므로 스크립트 파일을 저장소에 두지 않는다. 아래 코드를 임시 파일로 저장해 저장소 루트에서 실행하면 5장 표의 모든 수치를 재현할 수 있다.
출력 행의 마지막 두 칸(MDD 저점일, 종료 자산)은 6.3장과 5장 최종 자산의 근거다.

```python
"""Q-2-2XS 누적 성과 추이 — 시작일 고정, 종료일을 각 연도 말로 늘려가며 QQQ Buy & Hold 와 비교"""

from pathlib import Path

import pandas as pd

from qbt.backtest.analysis import calculate_summary
from qbt.backtest.constants import DEFAULT_INITIAL_CAPITAL
from qbt.backtest.engines.backtest_engine import run_backtest
from qbt.backtest.strategies.buy_and_hold import BuyAndHoldStrategy
from qbt.common_constants import QQQ_DATA_PATH
from qbt.utils.data_loader import load_stock_data

EQUITY_PATH = Path("storage/results/portfolio/portfolio_q2_2xs/equity.csv")
EMPTY_TRADES = pd.DataFrame(columns=["pnl"])

pf = pd.read_csv(EQUITY_PATH, usecols=["Date", "equity"])
pf["Date"] = pd.to_datetime(pf["Date"]).dt.date
start, end = pf["Date"].iloc[0], pf["Date"].iloc[-1]

# QQQ B&H: 같은 구간을 같은 엔진으로 실행 (첫날 신호 → 다음 날 시가 매수, 슬리피지 포함)
qqq = load_stock_data(QQQ_DATA_PATH)
qqq = qqq[(qqq["Date"] >= start) & (qqq["Date"] <= end)].reset_index(drop=True)
_, bh, _ = run_backtest(BuyAndHoldStrategy(), qqq.copy(), qqq.copy(), DEFAULT_INITIAL_CAPITAL, log_trades=False)
bh = bh[["Date", "equity"]].copy()
assert bh["Date"].tolist() == pf["Date"].tolist(), "거래일 불일치"


def cumulative(df: pd.DataFrame, year: int) -> tuple[dict, float, object, object]:
    """시작일부터 year 년 마지막 거래일까지 자른 구간의 요약 지표, 종료 자산, 종료일, MDD 저점일"""
    sub = df[pd.to_datetime(df["Date"]).dt.year <= year].reset_index(drop=True)
    summary = calculate_summary(EMPTY_TRADES, sub, DEFAULT_INITIAL_CAPITAL)
    drawdown = sub["equity"] / sub["equity"].cummax() - 1
    return summary, float(sub["equity"].iloc[-1]), sub["Date"].iloc[-1], sub["Date"].iloc[int(drawdown.idxmin())]


print(f"기간: {start} ~ {end} ({len(pf)}거래일)")
prev_pf = prev_bh = DEFAULT_INITIAL_CAPITAL
for year in sorted({d.year for d in pf["Date"]}):
    s_pf, eq_pf, last_day, trough_pf = cumulative(pf, year)
    s_bh, eq_bh, _, trough_bh = cumulative(bh, year)
    print(
        f"| ~ {last_day} "
        f"| {(eq_pf / prev_pf - 1) * 100:+.2f}% | {(eq_bh / prev_bh - 1) * 100:+.2f}% "
        f"| {s_pf['cagr']:.2f}% | {s_bh['cagr']:.2f}% | {s_pf['cagr'] - s_bh['cagr']:+.2f}%p "
        f"| {s_pf['mdd']:.2f}% | {s_bh['mdd']:.2f}% "
        f"| {s_pf['calmar']:.2f} | {s_bh['calmar']:.2f} "
        f"| 저점 {trough_pf} / {trough_bh} | 자산 {eq_pf:,.0f} / {eq_bh:,.0f} |"
    )
    prev_pf, prev_bh = eq_pf, eq_bh
```
