# MEMORY — 이 저장소에서 알아낸 것

> 이 저장소에서 알아낸 것 중 **모르면 틀리는 것**을 모은다(루트 `CLAUDE.md` 가 `@import` — 쓰는 규칙은 전역 「개인 프로젝트 공통」).

## 작업 방식

### 전략 용어는 풀어서 설명한 뒤 결론을 말한다

휩소 · 기회 · 프리미엄 · 버퍼존 · 고원 · WFO 같은 용어를 **연구 문서의 표기 그대로 대화에 꺼내지 않는다.**
`docs/research/` 문서는 용어를 정의해두고 쓰지만, 그 문서를 다시 읽지 않는 한 대화에서는 통하지 않는다.

선택지를 제시할 때는 이 순서로 쓴다 — ① 그 용어가 무엇인지 한 문장 ② 지금 상황의 구체적 숫자 ③ 그래서 무엇을 정해야 하는지. **질문 옵션의 라벨·설명에도 같은 규칙을 적용한다.**

용어만 풀어 써서는 부족하다 — 처음 듣는 사람 기준으로 쉬운 예시를 먼저 보이고, `-0.86 / +21.4` 같은 압축 표기 대신 실제 수익률 · 낙폭과 합격 · 불합격을 그대로 적는다 (사용자 요청 2026-11-01 「초보자가 쉽게 이해할수 있게」).

### 운용은 Q-2-2XS 이고, 전체 자산을 그것으로 두지 않는다

Q-2-2XS 는 SSO 35 · QLD 35(기존 버퍼존 4P) · GLD 15 · TLT 15(보유)인 `portfolio_q2_2xs` 다 (사용자 결정 2026-11-04). 전체 자산 중 일부만 이 매매법으로 운용한다 — 버퍼존은 구간에 따라 보유보다 나은 때와 나쁜 때가 있고 보유보다 더 번다는 근거가 없다 (사용자 결정 2026-11-08, 근거는 보고서 §2.5.11). 나머지를 1배 보유로 섞는 비율은 아직 정하지 않았다 — 별도 작업이다. 보고서 부록 M 의 채택 조합(HAA · 로테이션 섞기)은 철회했다 — 부록 M 을 읽고 그 조합을 운용안으로 잡지 않는다. 경위는 부록 O.

### 전략 연구에 합격 점수를 두지 않는다

합격선을 정하는 것 자체가 과최적화다 (사용자 결정 2026-11-01). 값을 바꾼 결과를 그대로 보이고, 과최적화인지부터 판단한다. 근거는 숫자 기준이 아니라 모양으로 낸다 — 옆 값으로 옮겨도 부드럽게 변하는가, 몇 건의 거래에 달렸는가, 안 본 구간에서도 같은 모양인가, 결과를 보고 고른 값인가.

### 버퍼존 레버리지는 1배 신호 · 종가 손절이다

2 · 3배를 잴 때도 이동평균 · 매수선 · 매도선 · 손절선을 1배 시세로 정하고 폭에 배수를 곱하지 않는다. 1배 종가가 손절선 아래로 마감하면 다음 날 시가에 판다 (사용자 결정 2026-11-01, 근거는 보고서 부록 N.21).

### 레버리지 전략은 1배 · 2배 · 3배를 나란히 비교한다

QQQ 와 TQQQ 만 견주지 않고 QLD 를 넣어 배수별로 본다 (사용자 요청 2026-11-01). 표마다 QLD 를 기계적으로 넣으라는 뜻이 아니다 — 한 배수 전용으로 정한 전략에는 넣지 않는다.

### 성과는 세전과 세후를 함께 낸다

해외주식 양도세(수익의 22%, 손실이면 0, 이월 없음)를 넣은 세후를 세전 옆에 둔다 (사용자 요청 2026-11-03 부터 계속). 「판 것만」 과세가 기본이고, 계산 방식은 보고서 부록 O.7.

### 「더 효율적인가」는 같은 낙폭 비교와 수익 쏠림으로 답한다

더 벌고 더 빠지는 안을 견줄 때 연 수익만 대지 않는다 — 현금이나 다른 배수를 섞어 최악 낙폭을 맞춘 뒤 연 수익을 견주고, 차이가 몇 해에 몰렸는지(그 해들을 빼면 뒤집히는지)를 함께 보인다 (2026-11-03 사용자 질문에 이렇게 답해 판단이 섰다 — 부록 O.9 · O.10).

### 낙폭만 보지 않고 진입가 대비 손익을 함께 본다

낙폭이 깊어도 진입가보다 높게 팔았으면 익절이다 (사용자 요청 2026-11-01). 전략 성과를 낼 때 MDD 와 함께 거래별 진입가 대비 손익을 보인다.
